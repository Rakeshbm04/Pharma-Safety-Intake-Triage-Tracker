A row is marked `Done` only if its cited test passes or its artefact exists. Two checks keep this file honest:
- `tests/test_offline_and_governance.py::test_acceptance_matrix_references_real_tests` fails if any test cited here does not exist.
- `tests/test_offline_and_governance.py::test_acceptance_matrix_rows_are_sequential_and_done` checks that rows are numbered in sequence and marked Done.

Run `python -m pytest -q` to verify every row.

## Documented deviations

- **No generative LLM call (§5 Stage 4).** The spec forbids external APIs, so the top chunks feed a *grounded generation prompt* that is built and shown in the UI, and the answer is composed extractively from verbatim sentences with `[source_id]` citations. Plugging in a locally hosted LLM later only needs `build_prompt` in `app/rag/pipeline.py`.
- **Calibrated cross-encoder (§5 Stage 4).** The MS MARCO model's probability is blended 50/50 with a domain-aware joint scorer (`RERANK_NEURAL_WEIGHT`). The reasoning and the evidence are in `docs/DEMO_EVIDENCE.md` and `docs/REFLECTION.md` §4.

## Edge cases covered beyond the spec

Unicode round-trip, SQL-injection strings, LIKE-wildcard search, double and concurrent identical submits, a duplicate not consuming a reference number, concurrent transitions (exactly one wins), migration of an older database, stopword-only and empty RAG queries, an empty corpus, unknown references, a frozen record while closure is pending, self-approval, wrong-role approval, and a runtime network guard during the whole test session.
