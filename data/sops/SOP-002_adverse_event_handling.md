# SOP-002 Suspected Adverse Event Intake Handling (Fictional Training SOP)

Fictional procedure for capturing suspected adverse event information. The tracker is not a pharmacovigilance database and must not be used to evaluate events.

## Capturing the Event

Record the event exactly as described by the reporter, in the reporter's own words where possible. Common lay descriptions include shortness of breath or difficulty breathing (recorded clinically as dyspnea), hives or itchy welts (urticaria), feeling sick (nausea), throwing up (vomiting), dizziness and fainting. The operator must not translate a lay description into a diagnosis.

## Event Onset Date

Ask the reporter for the date the event started. If only an approximate date is known, record the best available date and mention the uncertainty in the event description. The onset date must be on or before the date the report was received.

## Breathing and Allergic-Type Descriptions

When a reporter describes breathing difficulty, throat swelling, facial swelling or a severe allergic reaction, complete the intake promptly and move the report to In Review on the same day so a qualified reviewer sees it quickly. The intake operator does not judge seriousness and does not give any advice about what the person should do medically; callers asking for medical advice are directed to their healthcare professional or local emergency services.

## Follow-up Information

Additional information received later about the same case is linked to the existing reference number in the description of a new note to the reviewer. Do not create duplicate reports for the same event.
